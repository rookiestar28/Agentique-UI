# Heddle Package Disposition

Agentique keeps its accepted run protocol and does not add a Heddle product dependency.

The exact runtime and run-client tarballs passed integrity, MIT license, lifecycle-script,
advisory, and no-effect probes. Import safety alone is not an adoption reason. The runtime would
add a packaged Node prerequisite and a broad installed graph; the run client would add redundant
protocol/transport adaptation while omitting Agentique's complete-address, conflicting-duplicate,
and safe-payload guarantees.

The recorded disposition is `NO_ADOPT`. This is an accepted feasibility result, not a claim that
the upstream packages are unsafe. Agentique may reuse the reviewed lifecycle concepts through its
own public contracts, but Heddle types do not become Agentique API types.

Rollback is complete by construction: no dependency or lockfile change is retained, no HTTP/SSE
or content-security-policy capability is added, and no installed Node runtime becomes a product
prerequisite. A future reconsideration requires a new exact-version audit and a concrete product
gap that cannot be closed more narrowly by Agentique-owned code.
